# Submodels And Correlation Modeling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the first linear modeling checkpoint so the notebook and script compare the v2 main model against mechanism submodels and explain ElasticNet results with train-period correlation diagnostics.

**Architecture:** Keep reusable modeling logic in `3_models/scripts/`, with one orchestration module for panel experiments and one diagnostics module for correlations. `run_modeling.py` remains the notebook entry point and writes all reproducible outputs. The notebook imports the script, displays generated tables and figures, and checks that every output artifact can be regenerated by executing the notebook.

**Tech Stack:** Python, pandas, numpy, scikit-learn, matplotlib, seaborn, pytest, Jupyter.
